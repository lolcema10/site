Soundpad

1.0.0 · sema · MIT

Свои звуки, которые слышат игроки с Simple Voice Chat. Ползунок громкости от 0 до 100% запоминается. Меню открывается клавишей «Открыть саундпад».

  • Клиент и сервер
  • Fabric API
  • Simple Voice Chat 2.6+

Как поставить

  1. Поставь Fabric Loader для Minecraft 26.3. Нужна Java 25.
  2. Скачай Fabric API под ту же версию и положи jar в папку mods.
  3. Скачай мод с этой страницы в ту же папку и запусти игру с профилем Fabric.
  4. Для Soundpad поставь ещё Simple Voice Chat (API 2.6 или новее). Без него мод не загрузится.

Windows %appdata%\.minecraft\mods

macOS ~/Library/Application Support/minecraft/mods

Linux ~/.minecraft/mods
